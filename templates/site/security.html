About & security

How we handle compensation data

What we store, what we share, what is demo-only, and what isn't built yet. We'd rather tell you plainly than overstate it.

{{ icon('lock') }}

Tenant-private by default

Company profile, SaaS metrics, cash and burn, bands, requisitions and offers belong to your workspace. Financial inputs never leave it.

{{ icon('consent') }}

Consent before sharing

Outcomes enter the shared benchmark only when your workspace has data sharing on. Shared rows hold role, level, city tier, bands and amounts - no names, no company identity (a salted hash), city reduced to its tier.

{{ icon('cohort') }}

Minimum aggregation

A real-data benchmark needs at least 10 accepted offers from at least 3 companies (configurable upward). Below that, nothing is shown.

{{ icon('audit') }}

Tamper-evident history

Submissions, approvals and metric snapshots can't be edited. The audit log is hash-chained, and an integrity check recomputes the chain so a direct database edit shows up.

{{ icon('candidate') }}

Candidate data

Benchmarks never need a candidate's name. Names, when entered, are purged from closed offers after a retention period you set, and never appear in shared data.

{{ icon('demo') }}

Demo data, labelled

The demo model is trained on a synthetic dataset calibrated to published ranges. Its accuracy figures describe the synthetic data only, and it cannot run in pilot or production workspaces.

Not built yet

  • {{ icon('warning', 20) }}Single sign-on. The demo uses a user switcher and only runs when explicitly enabled.
  • {{ icon('warning', 20) }}PostgreSQL with managed secrets, backups and India data residency. The demo uses a local SQLite file.
  • {{ icon('warning', 20) }}Anchoring the audit hash to an external append-only store.
  • {{ icon('warning', 20) }}Independent security assessment.

Data processing requests

Design partners sign a data-sharing agreement before any records are imported. For a DPA, a deletion request, or questions about India's DPDP Act obligations, apply through the pilot form and mention it in the notes; we'll respond from a named contact.
