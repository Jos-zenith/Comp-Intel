How this differs from an offer's benchmark

  • Benchmarks on offers are frozen when the offer is created, so a submission can always be reproduced. This page is the live view; Re-benchmark on an offer adopts newer data.
  • Data comes only from the consented benchmark network: shared workspace outcomes (including those arriving from HRIS/ATS integrations) and design-partner imports.
  • Observation dates are month-level on purpose (privacy), so each offer counts as mid-month for the window and recency weight.
  • Event bus: {{ backend }}. Set COMPINTEL_STREAM_BACKEND=redis and COMPINTEL_REDIS_URL to run the worker and the live push across several server processes.
